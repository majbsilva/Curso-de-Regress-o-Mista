# Módulo 6 - Como escolher a estrutura aleatória

Do simples ao complexo, guiado pelos dados.

## O que o aluno faz neste módulo

O aluno aprende a começar simples (1|id) e ampliar só se os dados pedirem, usando AIC/BIC e teste de razão de verossimilhança.

## Arquivo principal

- Mestre: `Módulo 6 - Estrutura aleatoria.qmd`
- Template do aluno: `Módulo 6 - Estrutura aleatoria — TEMPLATE.qmd` (gerado a partir do mestre)

## Como rodar

1. Abra o projeto R do curso (Curso de Regressão Mista.Rproj) no RStudio.
2. Abra o arquivo-mestre em Quarto e rode bloco a bloco, OU abra o template e preencha junto com o professor.
3. Depois, renderize o HTML para revisão: `quarto render "Módulo 6 - Estrutura aleatoria.qmd"`.
