Estrutura do modelo misto

A forma matemática traduzida para uso prático

Author

Marcelo Silva

1 A equação

O modelo misto linear (resposta contínua) tem a forma:

y = X * beta + Z * b + e

Onde:

  • y é a variável resposta.
  • X * beta são os efeitos fixos (o que interpretamos).
  • Z * b são os efeitos aleatórios (a variação entre grupos).
  • e é o erro residual.

A parte aleatória assume distribuição, em geral normal, com sua própria variância. O modelo estima as médias dos fixos e as variâncias dos aleatórios.

2 Traduzindo para a fórmula do R

No lme4, escrevemos a parte fixa à esquerda e a aleatória entre parênteses à direita:

lmer(resposta ~ fixos + (1 | grupo), data = d)

O (1 | grupo) diz: cada grupo tem sua própria interceptação (linha de base).

3.1 Vamos observar o gráfico de macarrão

library(tidyverse)
sleepstudy %>% 
  ggplot(aes(x = factor(Days), y = Reaction, colour = Subject))+
  geom_line(aes(group = Subject))

Veja no gráfico acima, que cada a reação de cada sujeito ao longo do tempo é diferente. Vamos ver isso no modelando com a inclinação aleatória

modelo_inclinacao_aletaoria <- lmer(Reaction ~ Days + (1 + Days | Subject), data = sleepstudy)

ImportantAqui vai uma observação extremamente importante

Quando se modela inclinação aleatória, o dfs efetivo para o efeito dentro-cluster cai para o número de clusters (18 sujeitos → df≈17). O lm e o lmer com apenas intercepto aleatório fingem que têm muitos graus de liberdade (180 linhas - numero de sujeitos[18] - 1 intercepto → df≈162).

O modelo com inclinação aleatória honestamente reconhece que a unidade de replicação para a inclinação média são os sujeitos.

4 Por que isso importa

Harrell defende especificar a estrutura de covariância explicitamente. O termo aleatório é onde declaramos como os dados estão correlacionados, e não fingimos independência.
