Cenário de bancada com pacientes e visitas

1 O cenário

Pacientes com hipertensão avaliados na pressão sistólica em três visitas (dia 0, 30, 60), comparando dois tratamentos (tratado e controle).

2 Preparando dados simulados

# Crie um dataset de medidas repetidas com dois tratamentos
set.seed(2024)
pac <- 1:40
d <- expand.grid(paciente = pac, visita = c(0, 30, 60))
d$tratamento <- ifelse(d$paciente <= 20, "Tratado", "Controle")
# interceptação por paciente (aleatório) + efeito de tratamento e visita (fixos)
base_pac <- rnorm(40, 120, 8)
y <- numeric(nrow(d))
for (i in seq_len(nrow(d))) {
  b <- base_pac[d$paciente[i]]
  trt <- ifelse(d$tratamento[i] == "A", -5, 0)
  vis <- 0.2 * d$visita[i]
  y[i] <- b + trt + vis + rnorm(1, 0, 3)
}
d$pas <- y
head(d)
