# Módulo 10 - Roteiro de exercícios

Prática guiada para fixar o conteúdo.

## O que o aluno faz neste módulo

O aluno pratica com dados simulados e com os casos C1 e C2.

## Arquivo principal

- Mestre: `Módulo 10 - Exercicios.qmd`
- Template do aluno: `Módulo 10 - Exercicios — TEMPLATE.qmd` (gerado a partir do mestre)

## Como rodar

1. Abra o projeto R do curso (Curso de Regressão Mista.Rproj) no RStudio.
2. Abra o arquivo-mestre em Quarto e rode bloco a bloco, OU abra o template e preencha junto com o professor.
3. Depois, renderize o HTML para revisão: `quarto render "Módulo 10 - Exercicios.qmd"`.

## Observação

Os templates são gerados automaticamente a partir do mestre com `_ferramentas/gerar_template.R`. Não edite o template diretamente.
